FriesGo Global 隐私政策（Privacy Policy）

生效与核查日期：2026-11-27（UTC+8）｜适用站点：FriesGo Global 工业品外贸工作台

1. 概览：访客本地存储与公司云端存储严格隔离

我们坚持最小权限与数据隔离原则，区分处理访客本地数据与公司内部员工云端数据：

  • 外部访客（未登录）：您在报价计算、开发信生成、本地客户草稿或本机反馈记录中填写的内容仅保存在您当前浏览器的 localStorage 与 IndexedDB 中。FriesGo 后端服务器不会收集或读取外部访客的本地业务数据。
  • 内部员工（已认证登录）：经公司管理员开通独立账号并登录后，团队共享的企业线索、跟进记录、防撞单锁、报价记录、审核日志与云端共创反馈将加密传输（HTTPS）并存储在公司独立的 Cloudflare D1 数据库中，所有私密接口响应均标记 Cache-Control: no-store。

2. 认证凭据与密钥的保管方式

  • 员工密码与 2FA：服务端采用 PBKDF2-HMAC-SHA256（100,000 次迭代 + 独立随机盐 + 服务端 Pepper）单向派生保存，绝不保存明文密码；管理员 TOTP 2FA 密钥使用 AES-256-GCM 加密存储，应急恢复码仅保存单向哈希。
  • 登录会话与退出清理：浏览器仅在员工登录后于当前设备保存临时 Bearer 会话令牌；主动退出、密码重置或账号被管理员禁用后，系统立即失效服务端会话并清除本机私有云端缓存与离线待传队列。
  • 个人直连 API Key：若您主动在地图配置区填写个人 Google API Key 或自定义代理口令，该凭据仅保存在您当前浏览器的 localStorage，不会上传至 FriesGo 静态页面仓库；请在公共电脑使用后及时清除。

3. 外部第三方服务与数据流向（含 Google Privacy Policy）

Google Maps / Google Places 隐私声明：当您使用本工作台的 Google Maps 找客功能时，您的搜索词、城市或地理范围查询将经由公司认证代理或直连方式发送至 Google Maps Platform 接口。使用该功能即表示您知悉并受 Google 隐私政策（Google Privacy Policy） 以及 Google Maps / Google Earth 附加服务条款 约束。

根据您主动点击的功能，浏览器或服务端可能向以下第三方公开接口发起必要请求：

  • Google Maps Platform Places API：仅在您点击 Google 地图找客时发送检索查询；不缓存或导出 Google 原始客户字段。
  • OpenStreetMap（Overpass API / Photon / Nominatim）：仅在您使用开源地图找客时发送城市坐标与工业关键词查询。
  • Cloudflare DNS-over-HTTPS（DoH）：仅在您点击邮箱域 MX 核验时查询目标企业域名是否存在邮件交换记录（不发送个人邮箱账号）。
  • GLEIF / ExchangeRate / 世界银行 / GDACS：仅用于公开企业 LEI 核查、参考汇率及公开商机数据拉取。

4. 反馈卡片与诊断上下文边界

「反馈/提建议」功能自动附带的诊断上下文采用严格白名单，仅记录当前页面模块名、当前选定品类/国家、视口尺寸、浏览器类型、版本号、时间戳（UTC+8）与经脱敏处理的最近一条前端报错，绝不自动读取客户库或报价明细。您在自由文本框中输入的内容会做基础自动脱敏（邮箱、号码、链接、常见口令/密钥格式与金额），但技术手段无法保证 100% 识别所有自然语言中的人名或公司名，发送前请您人工复核。

5. 数据保留、导出与删除

  • 本机数据：您可随时通过工作台内的 JSON 导出/清空按钮或浏览器清除站点数据功能删除本地存储。
  • 公司云端数据：内部员工账号权限调整、离职禁用、设备踢下线、数据备份导出或合规删除请求，均由公司最高管理员（super_admin）在管理后台操作并写入不可篡改的审计日志。
